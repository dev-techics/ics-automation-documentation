Configuration

This document covers every configuration option available in the ICS Automation backend. Configuration is managed through the .env file and Laravel configuration files in the config/ directory.

Environment Variables​

The .env file is the primary configuration source. It is never committed to version control — only .env.example (a template with placeholder values) is tracked in Git.

Application Settings​

VariableTypeRequiredDefaultDescription
APP_NAMEstringYesLaravelDisplay name of the application. Appears in log files and error pages.
APP_ENVstringYesproductionEnvironment name. Use local for development, production for live. Affects error display, caching, and logging verbosity.
APP_KEYstringYes—Base64-encoded encryption key. Generated by php artisan key:generate. Used for encrypting cookies, sessions, and passwords.
APP_DEBUGbooleanYesfalseWhen true, detailed error pages with stack traces are shown. Never enable in production.
APP_URLstringYeshttp://localhostBase URL of the application. Used for generating absolute URLs (e.g., unsubscribe links).
FRONTEND_URLstringYes—URL of the React frontend. Used for redirecting users after unsubscribe/subscribe actions.

Example:

APP_NAME="ICS Automation"
APP_ENV=local
APP_KEY=base64:xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
APP_DEBUG=true
APP_URL=https://automation.icslegal.com
FRONTEND_URL=https://automation.icslegal.com

Database Settings​

VariableTypeRequiredDefaultDescription
DB_CONNECTIONstringYesmysqlDatabase driver. Currently only mysql is supported.
DB_HOSTstringYes127.0.0.1Database server hostname or IP address.
DB_PORTintegerYes3306MySQL port number.
DB_DATABASEstringYes—Database name. Must be the Legal CMS database (shared with other CMS tables).

Example:

DB_PASSWORD=

Table Prefix​

The table prefix is not set in .env. It is hardcoded in config/database.php:

'prefix' => 'ics_automation_',

This means all application tables are created with the ics_automation_ prefix (e.g., ics_automation_flows, ics_automation_clients). The prefix isolates automation tables from CMS tables in the shared database.

To change the prefix, edit config/database.php:

'prefix' => 'your_custom_prefix_',

Warning: Changing the prefix after tables have been created will cause the application to look for tables that do not exist. All existing data will be inaccessible.

SendGrid (Email Service)​

VariableTypeRequiredDefaultDescription
SENDGRID_APIKEYstringYes—SendGrid API key. Must have Mail Send permission. Format: SG.xxxxxxxxxx.
SENDGRID_APIENDPOINTstringYeshttps://api.sendgrid.com/v3/mail/sendSendGrid mail send endpoint URL.

Example:

SENDGRID_APIKEY=SG.xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
SENDGRID_APIENDPOINT=https://api.sendgrid.com/v3/mail/send

How SendGrid is Used:

  • SendEmailAction sends emails via the SendGrid REST API
  • Each email includes custom_args with smart_automation_exe_id and node_id for webhook correlation
  • SendGrid sends webhook events to /sendgrid/events for delivery tracking

Required SendGrid API Permissions:

PermissionRequiredWhy
Mail SendYesSending emails
Event WebhookYesReceiving delivery/open/click events
Template EngineNoTemplates are managed in-app, not SendGrid

Sendmode (SMS Service)​

VariableTypeRequiredDefaultDescription
SENDMODE_USERNAMEstringYes—Sendmode account username. Used for SMS sending authentication.
SENDMODE_PASSWORDstringYes—Sendmode account password. Used for SMS sending authentication.
SENDMODE_API_KEYstringYes—Sendmode API key. Used for checking remaining credit balance.

Example:

SENDMODE_USERNAME=ics_legal
SENDMODE=your_password
SENDMODE_API_KEY=your_api_key

How Sendmode is Used:

  • SendSmsAction sends SMS via Sendmode's HTTP POST API (https://api.sendmode.com/httppost.aspx)
  • Each SMS includes a CustomerID in the format {executionId}-{nodeId} for delivery receipt correlation
  • Sendmode sends delivery receipts to /sendmode/dlr
  • CreditController fetches remaining credits from http://rest.sendmode.com/v2/credits

SMS Sender ID:

The sender ID is hardcoded as ICS Legal in SendSmsAction. To change it, edit the action class.

Queue & Cache Settings​

VariableTypeRequiredDefaultDescription
QUEUE_CONNECTIONstringYesdatabaseQueue driver. Supported: database, sync, redis, sqs.
CACHE_DRIVERstringYesdatabaseCache driver. Supported: database, file, redis, memcached.
SESSION_DRIVERstringYesdatabaseSession driver. Supported: database, file, cookie, redis.

Example:

QUEUE_CONNECTION=database
CACHE_DRIVER=database
SESSION_DRIVER=database

Queue Driver Options​

DriverDescriptionWhen to Use
databaseStores jobs in MySQL jobs table. Simple, no external dependencies.Development, low-to-medium traffic
syncProcesses jobs synchronously (no queue). Blocks the request.Testing only — never in production
redisStores jobs in Redis. Fast, supports advanced features.High-traffic production environments
sqsStores jobs in AWS SQS. Fully managed.AWS-hosted deployments

Queue Table​

When using the database driver, jobs are stored in:

ics_automation_jobs

Failed jobs are stored in:

ics_automation_failed_jobs

These tables are created by Laravel's default queue migrations:

php artisan queue:table
php artisan queue:failed-table
php artisan migrate

CORS Settings​

CORS (Cross-Origin Resource Sharing) is configured in config/cors.php:

return [
    'paths' => ['api/*', 'sanctum/csrf-cookie'],
    'allowed_methods' => ['*'],
    'allowed_origins' => [
        'http://localhost:3000',
        'http://localhost:3001',
        'http://localhost:5173',
        'https://automation.icslegal.com',
        'https://staginglegalcms.techics.com',
        'https://cms.icslegal.com',
    ],
    'allowed_origins_patterns' => [],
    'allowed_headers' => ['*'],
    'exposed_headers' => [],
    'max_age' => 0,
    'supports_credentials' => true,
];
SettingValueDescription
paths['api/*']Which URL paths CORS applies to
allowed_methods['*']All HTTP methods allowed (GET, POST, PUT, DELETE)
allowed_originsArray of URLsOnly these domains can make cross-origin requests
allowed_headers['*']All request headers allowed
supports_credentialstrueAllows cookies and authentication headers

Adding a New Origin:

To allow a new frontend domain, add it to the allowed_origins array:

'allowed_origins' => [
    // ... existing origins
    'https://new-domain.com',
],

Configuration Files​

Beyond .env, the following configuration files in config/ control application behavior:

config/app.php​

Controls application-level settings:

'timezone' => 'UTC',
'locale' => 'en',
'fallback_locale' => 'en',

config/database.php​

Controls database and queue table settings:

'mysql' => [
    'driver' => 'mysql',
    'host' => env('DB_HOST', '127.0.0.1'),
    'port' => env('DB_PORT', '3306'),
    'database' => env('DB_DATABASE', 'cms'),
    'username' => env('DB_USERNAME', 'root'),
    'password' => env('DB_PASSWORD', ''),
    'prefix' => 'ics_automation_',
    'strict' => true,
    'engine' => null,
],

config/queue.php​

Controls queue behavior:

'database' => [
    'driver' => 'database',
    'table' => 'jobs',
    'queue' => 'default',
    'retry_after' => 90,
    'after_commit' => false,
],

'failed' => [
    'driver' => env('QUEUE_FAILED_DRIVER', 'database-uuids'),
    'database' => env('DB_CONNECTION', 'mysql'),
    'table' => 'failed_jobs',
],
SettingDescription
retry_afterSeconds before a job is re-queued if the worker crashes while processing it
queueDefault queue name. Jobs can specify different queues for prioritization
after_commitWhen true, jobs are dispatched only after the database transaction commits

config/logging.php​

Controls log output:

'default' => env('LOG_CHANNEL', 'stack'),

'channels' => [
    'stack' => [
        'driver' => 'stack',
        'channels' => ['single'],
        'ignore_exceptions' => false,
    ],
    'single' => [
        'driver' => 'single',
        'path' => storage_path('logs/laravel.log'),
        'level' => env('LOG_LEVEL', 'debug'),
    ],
    'daily' => [
        'driver' => 'daily',
        'path' => storage_path('logs/laravel.log'),
        'level' => env('LOG_LEVEL', 'debug'),
        'days' => 14,
    ],
],
ChannelDescription
singleAll logs in one file (laravel.log)
dailyRotated daily (laravel-2026-05-20.log), keeps 14 days
stackCombines multiple channels

Service Configuration​

Email Template Placeholders​

Email templates support the following placeholder variables that are replaced at send time:

PlaceholderReplaced WithSource
{UNSUBSCRIBE_URL}Full unsubscribe URL with unique hashGenerated from FlowExecution.hash
{CLIENT_FIRST_NAME}Contact's first namemembers.fname
{CLIENT_LAST_NAME}Contact's last namemembers.lname
{CLIENT_EMAIL}Contact's email addressmembers.email

The {UNSUBSCRIBE_URL} placeholder is mandatory for compliance. It is automatically replaced by SendEmailAction:

$unsubscribeUrl = config('app.url') . '/unsubscribe?hash=' . $execution->hash;
$html = str_replace('{UNSUBSCRIBE_URL}', $unsubscribeUrl, $template->html);

SMS Credit Calculation​

SMS credits are calculated based on message length:

function calculateCredits(string $content): int
{
    $chars = strlen($content);

    if ($chars <= 160) {
        return 1;
    }

    if ($chars <= 299) {
        return 2;
    }

    if ($chars <= 440) {
        return 3;
    }

    // Concatenated SMS: 153 characters per segment after the first 160
    return 1 + (int) ceil(($chars - 160) / 153);
}
Message LengthSegmentsCredits (UK)Credits (International)
1–160112.5
161–299225
300–440337.5
441–5934410
594–7465512.5

Mobile Number Validation​

SendSmsAction validates and normalizes mobile numbers:

  1. Comma-separated numbers: If the mobile field contains multiple numbers separated by commas, only the first valid number is used
  2. UK format conversion: Numbers starting with 07 are converted to 44 format (e.g., 07123456789 → 447123456789)
  3. Length validation: Numbers must be 10–15 digits after removing non-numeric characters

Configuration Checklist​

Before deploying to production, verify the following:

  • APP_ENV is set to production
  • APP_DEBUG is set to false
  • APP_KEY is generated and unique
  • APP_URL is set to the production URL
  • FRONTEND_URL is set to the production frontend URL
  • Database credentials are correct and the cms database exists
  • SENDGRID_APIKEY is set with Mail Send permission
  • SENDMODE_USERNAME, SENDMODE_PASSWORD, and SENDMODE_API_KEY are set
  • QUEUE_CONNECTION is set to database (or redis for high traffic)
  • Queue worker is running (via Supervisor or equivalent)
  • CORS allowed_origins includes the production frontend URL
  • Log channel is set to daily for production
  • .env file is not committed to version control
